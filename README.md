# 粒子滤波（蒙特卡洛定位，MCL）

仅使用 **Go 标准库** 实现的二维机器人粒子滤波定位，包含退化检测、两种重采样
算法的统计对比、对称环境多峰维持实验，以及一个**完全内嵌、无第三方依赖**的
单文件 HTML 报告（逐帧回放 + ESS 曲线），浏览器直接打开即可。

## 目录结构

```
particle.go      粒子/位姿/运动噪声等基础类型与加权均值
filter.go        粒子滤波器：运动模型、观测更新、ESS、两种重采样、自适应重采样、抖动
simulation.go    仿真器：带标签/匿名观测、退化实验、多峰实验、帧快照
scenarios.go     两个实验世界的定义
stats.go         重采样蒙特卡洛统计（均值/样本方差/理论方差）
particle_test.go 自动化测试
cmd/report/      报告生成器：运行三组实验并输出 report.html（数据与 JS/CSS 全内嵌）
report.html      生成产物：单文件静态报告
```

## 模型

### 状态与运动模型

状态为二维位姿 `(x, y, θ)`。运动指令简化为“先原地旋转 `turn`、再平移 `dist`”：

```
θ' = wrap(θ + turn + ε_turn),  ε_turn ~ N(0, σ_turn²)
x' = x + (dist + ε_dist)·cos(θ')
y' = y + (dist + ε_dist)·sin(θ'),  ε_dist ~ N(0, σ_dist²)
```

### 观测模型

观测为到已知路标的**纯距离**。对路标 `k`：

```
p(z_k | x) = N( d(x, lm_k) − z_k ; 0, σ_range²)
```

权重在**对数空间累积**，归一化前做最大值平移（log-sum-exp），避免连乘下溢；
全部似然下溢为 0 时退化为均匀权重，杜绝 NaN。

- `Observe`：带标签距离观测，路标可区分；范围外路标的读数为 `NaN`，被忽略。
- `ObserveAnonymous`：**无标签**距离多重集。粒子把可见路标预测距离排序后
  与观测逐位匹配。对称环境中镜像位姿的距离多重集完全相同，因此似然严格相等。

### 有效粒子数与退化检测

```
N_eff = 1 / Σ_i w_i²
```

取值范围 `[1, N]`：权重均匀时为 `N`，全部质量集中于一个粒子时为 `1`。
实验一采用常见判据 `N_eff < 0.25·N` 判定退化，`DegradationStart` 返回
**首次越限的时间步**。实验一全程不重采样，纯粹展示重要性权重的退化：
机器人初始在路簇探测范围外（观测为空、ESS=N），逼近路簇时约束收紧、
ESS 骤降到个位数。

## 重采样算法

两者都基于归一化权重的 CDF，且都是**无偏**的（每个粒子的期望子代数 = N·w_i），
区别只在子代计数的方差：

- **多项式重采样（MultinomialResample）**：每个子代独立按权重有放回抽取。
  单个粒子子代数服从 `Binomial(N, w_i)`，理论方差 `N·w·(1−w)`；粒子可能被
  抽到很多次，也可能一次都抽不到，样本贫化严重。
- **低方差重采样 / 系统重采样（LowVarianceResample）**：在 CDF 上等间距
  `1/N` 放置 N 个采样点，**只做一次整体抖动** `U(0, 1/N)`。每个粒子的子代数
  被限制在 `floor(N·w_i)` 或 `ceil(N·w_i)`，计数方差接近于零，且每个
  `w_i ≥ 1/N` 的粒子保证至少得到一个子代。

`AdaptiveResample` 仅在 `N_eff < ratio·N` 时触发，避免不必要的样本贫化；
重采样后可调用 `Jitter` 做小幅高斯“再激活”。

### 算法选择依据

需要覆盖度稳定、避免少数粒子被重复抽取主导（尤其在全局定位初期、多峰后验
场景）时优先低方差重采样；它以相同的无偏性换取小得多的蒙特卡洛方差。
代价是子代之间存在系统性相关（不完全独立），且仍需配合自适应触发与抖动
来防止长期样本贫化。

## 三个实验

1. **退化检测**（`RunDegradation`）：纯重要性采样不重采样，观察 ESS 从 N
   骤降并定位退化起始时间步。
2. **重采样统计对比**（`CompareResampling`）：固定同一权重分布，每种算法
   独立重复 4000 次，用经验均值/样本方差与理论方差量化差异，而非只凭理论断言。
3. **多峰维持**（`RunMultimodal`）：路标关于 y 轴成对镜像、但 y 坐标不对称，
   使环境只有一个镜像对称方向，正确后验恰为两个峰 `(±5, y)`。观测为无标签
   距离多重集，且**镜像对共享同一噪声实现**（`SenseAnonymousSymmetric`），
   保证噪声模型也严格对称。配合“自适应低方差重采样 + 各向异性抖动 + 充足
   粒子（N=30000）”，后验全程维持双峰。

> 多峰场景的工程要点：首步全局定位观测必须足够“软”（较大的 σ、有限探测
> 距离），否则第一次重采样就会因随机权重差抹掉一个峰；有限 N 下重采样本身
> 是有方差的随机遗传漂变过程，对称后验需要足够多粒子 + 重采样后抖动来对抗。

## 运行

```bash
go test ./...            # 自动化测试
go run ./cmd/report      # 重新生成 report.html，然后用浏览器直接打开
```

测试覆盖：ESS 公式正确性（均匀→N、集中→1）、退化场景检出与起始步定位、
两种重采样的无偏性与方差差异（低方差重采样经验方差远小于多项式的理论
方差 `N·w(1−w)`）、低方差重采样对高权重粒子的覆盖性、多峰场景不塌缩。
